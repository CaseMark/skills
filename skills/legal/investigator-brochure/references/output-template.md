# Output Template

Layout for the Investigator's Brochure draft and its companion documents. Replace bracketed text; keep every heading and say why a section is empty.

## Contents

- Title page
- Table of contents
- Draft IB layout
- Source and consistency log
- Summary of changes
- Reviewer checklist

## Title Page

```
[SPONSOR NAME]
Product:             [research number]
Name(s):             [chemical name, generic name if approved, trade name if permitted and wanted]
INVESTIGATOR'S BROCHURE
Edition number:      [n]
Release date:        [date]
Replaces edition:    [n-1], dated [date]      (first edition: "none")
Data cut-off date:   [date]
Confidential: [confidentiality statement, if the sponsor wants one]
```

## Table of Contents

Numbered to the third level, then abbreviations. The sections, in order: Summary; Introduction; Physical, chemical and pharmaceutical properties and formulation; Nonclinical studies (pharmacology; pharmacokinetics and product metabolism in animals; toxicology); Effects in humans (pharmacokinetics and metabolism; safety and efficacy; marketing experience); Summary of data and guidance for the investigator (including the reference safety information and the safety margins table). References at the end of each chapter.

## Draft IB Layout

Draft all sections in that order. Rules for the draft:

- Summary last, preferably within two pages.
- Each nonclinical or clinical value has `[Study ID, Section, Table, p.]` or its Module 2.6 citation.
- Tables inside Sections 4 to 6 so investigators can cross-reference quickly.
- The reference safety table is headed and identifiable.
- If the sponsor supplies a Word template, preserve its numbering, styles, headers, footers and table formats, and place the content in it.

## Source and Consistency Log

| Section | Inputs used | Conflicts found | `[VERIFY]` items | `[SPONSOR INPUT REQUIRED]` items |
|---|---|---|---|---|

Add a short list of consistency checks run and their result: Summary values match body; doses match the protocol; reference safety list matches the human and nonclinical sections; safety margins match the Module 2.4 table.

## Summary of Changes

For editions after the first:

| Section | Change from prior edition | Reason (new data, correction, new reference) | Affects reference safety list? |
|---|---|---|---|

Say whether the reference safety list changed, because that changes what is expected.

## Reviewer Checklist

```
For the medically qualified editor and the owners of the data. Confirm each item.
[ ] Every value matches its cited source; Module 2.6 numbers match where used
[ ] Reference safety list: terms, frequencies, basis labels and sources
[ ] Safety margins: human exposure source and a common basis on both sides
[ ] Monitoring, thresholds and hold criteria are sponsor decisions and match the protocol
[ ] No promotional language; risks and benefits balanced
[ ] Edition number, supersession, release date and data cut-off date are correct
[ ] New safety information since the cut-off has been considered
[ ] Every [VERIFY] and [SPONSOR INPUT REQUIRED] item resolved
[ ] Approved by the disciplines that generated the data
```
