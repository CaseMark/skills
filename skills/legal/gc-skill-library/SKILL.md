# GC Skill Library Legal

Build, chain, and evolve AI-powered legal skills that operate as composable instruction sets — replacing repetitive prompt-pasting with reusable, self-improving skill modules.

## Prerequisites

- Legal practice area specialization for skill domain definition
- Existing precedent documents or playbooks as training data
- AI platform with skill composition and chaining capability

## Workflow

1. **Skill creation**: Compose a skill from natural language instructions or by reviewing existing precedent documents (e.g., "vendor NDA review rules")
2. **Skill attachment**: Attach the skill to any conversation or workflow without polluting the prompt text
3. **Skill chaining**: Chain multiple skills in sequence (e.g., contract review → clause extraction → redlining → summary)
4. **Skill creator refinement**: Improve skills through chat feedback — the system auto-incorporates corrections into the skill's instruction set
5. **Organization sharing**: Share skills across the legal team or organization for consistent application

## Pitfalls

- Skills should be narrowly scoped — one legal workflow per skill, not monolithic catch-alls
- Chained skills compound errors — test each link independently before full chain execution
- Self-improving skills require human validation before deployment to production workflows
- Skills must include explicit scope boundaries to prevent AI from overreaching into unauthorized practice of law
