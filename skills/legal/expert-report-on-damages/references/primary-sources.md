## How these sources were checked

All checks were made on 2026-10-30 through the case.dev API. "Full text via case.dev" means the official or court-published document was retrieved with the contents endpoint and the cited passage was read in context. "Excerpt" means the passage was read in a retrieved copy but the whole document was not read end to end; for scanned two-column reporter copies (courtlistener harvard_pdf files) the text was OCR and passages were read as excerpts. Every case citation below returned "verified" from the case.dev citation verifier (/legal/v1/verify, CourtListener source) on 2026-10-30. Before a report is served, re-read the current rule text for the forum and the scheduling order; Ground Rule 3 in SKILL.md requires it.
