## How these sources were checked

All checks were made on 2026-10-30. The first pass used web-search excerpts of official pages because direct page retrieval was blocked. A second pass the same day read the full text of each statute, regulation and key opinion through the case.dev API (`/search/v1/contents` for statute and opinion pages, `/legal/v1/verify` for reporter citations). Each row below gives the URL read, the method ("full text via case.dev" or "search excerpt") and the date. "Full text via case.dev" means the whole section or opinion was read, not a snippet; Justia and the Texas, Missouri, Washington and Florida legislature sites are unofficial compilations of the official text. Before any demand is sent, re-read the current statute; Ground Rule 6 in SKILL.md requires it.
