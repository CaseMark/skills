Method: web search restricted to the issuing body's own site (irs.gov, congress.gov, govinfo.gov, storage.fasb.org, occ.gov, fdic.gov, support.microsoft.com, newyorkfed.org), reading the text the search returned from each primary page. Direct page fetches of uscode.house.gov and law.cornell.edu were not available from the authoring session, so statutory text was read through govinfo.gov U.S. Code editions and IRS publications that quote it. Re-check every item before relying on it in a client-facing deliverable; tax figures change annually and Pub. L. 119-21 guidance is still being issued.
