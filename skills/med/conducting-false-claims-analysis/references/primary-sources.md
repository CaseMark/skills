## 1. How these sources were checked

All checks were made on 2026-10-30. "Full text via case.dev" means the page at the URL was retrieved through the case.dev contents or full-text API and each statement was compared with the passage read. Case citations were also run through the case.dev citation verifier, which matched each to a CourtListener record unless noted. The eCFR is the current unofficial compilation; re-read the current text of each statute and regulation before relying on it.
