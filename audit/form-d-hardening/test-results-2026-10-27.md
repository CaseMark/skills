## Observations and follow-ups

- Test 1 is less discriminating than intended: the fixture presents the scan's OCR text inline, so both skills found it. The revised skill's gain on that test is the register, the explicit "not Still needed" finding and the client question. A harsher variant would supply the scan as an image-only PDF in a real folder.
- Test 4's fixture originally left the base closing memo ($91,000,000) in the inventory alongside the changed subscriptions; the revised run flagged it as a stale-memo conflict (`revised-04.md:155`). The fixture now replaces the closing memo so the test isolates Item 11; expected behavior is unchanged.
- Every revised run reported the real lookup clock (October 27-28, 2026) beside the September 24 memo date and flagged the gap as an assumption; a harness that fixes the system clock would remove that noise.
- Every revised run raised the same two matters the fixtures did not plant: no individual bad actor questionnaire for the Investment Manager's officers (only the entity questionnaire), and whether 20 percent limited partners are covered persons. Both are reasonable flags on these facts and were not graded.
- Each revised run consumed roughly 170,000 to 205,000 tokens; the outputs are 330 to 500 lines. The worksheet columns roughly double the length of Section 3 compared with the baseline.
